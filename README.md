# Keylogger-for-Security-Awareness
📝 Description:
This project is an ethical keylogger developed in Python to raise security awareness by simulating real-world cyber threats. It captures keystrokes, clipboard content, screenshots, and system information, with all data encrypted using Fernet (symmetric encryption). Designed for educational and testing purposes, this tool highlights the importance of defensive strategies like anti-keyloggers, encrypted communication, and system monitoring. Data can be transmitted securely via HTTP POST or email for analysis.

🔐 Key Features:
Real-time keylogging using pynput

System info & clipboard monitoring

Screenshot capture with Pillow

Secure data encryption with cryptography

Periodic log uploads via HTTP/SMTP

Built-in awareness tool for cybersecurity learners

⚠️ Note:
This tool is intended strictly for ethical use in security testing, penetration testing, and educational contexts. Unauthorized use is prohibited.
